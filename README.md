# 💖 AIアイドル「カノン」のカスのウミガメのスープ 🍵

![AI Idol KANON](assets/kanon.jpg)

**メイド服風コスチュームの次世代AIアイドル「カノン」がゲームマスターを務める、理不尽でクスッと笑えるネタ水平思考パズル（カスのウミガメのスープ）Webアプリケーションです。**

Google Chrome のオンデバイスAI機能 **Chrome Built-in AI (Prompt API / Gemini Nano)** を活用し、サーバー不要・完全クライアントサイドで低レイテンシなキャラクター対話とゲーム判定を実現しています。

---

## ✨ アプリの特徴

1. **オンデバイスAI対話 (Chrome Built-in AI / Prompt API)**
   - ブラウザ内部の `window.LanguageModel`（Gemini Nano）と直接対話。
   - サーバーレス・プライバシー安全・オフライン動作対応。
   - ※Prompt API未対応ブラウザでも遊べる高精度シミュレータエンジンを自動フォールバック搭載！
2. **全12問のオリジナル「カスのウミガメ」問題**
   - 1問ごとに独立した完全なシステムプロンプトを注入。
   - カノンらしい天真爛漫・ポンコツ・理不尽なオチが満載！
3. **サイバーアイドル＆グラスモフィズムUI**
   - ピンク×ネオンパープルを基調としたリッチなWebデザイン。
   - カノンのアバター立ち絵＆吹き出しチャット。
   - クイック質問チップ、質問回数カウンター、ギブアップ機能、正解時の紙吹雪（Confetti）演出。

## 🚀 遊び方 / ローカル実行

本アプリは外部ビルドツール不要の純粋な HTML / CSS / JavaScript で構築されています。

```bash
# リポジトリをクローン
git clone https://github.com/<your-username>/ai-idol-kasu-umigame.git
cd ai-idol-kasu-umigame

# ローカルサーバー起動（Pythonの場合）
python -m http.server 8085
```

ブラウザで `http://localhost:8085` にアクセスしてください。

## 🌐 GitHub Pagesでの無料公開

本アプリは静的ファイルのみで構成されているため、**GitHub Pages** で誰でもブラウザから直接遊べるように公開できます。

1. GitHub リポジトリの **Settings** > **Pages** を開く。
2. **Branch** に `main` を指定して **Save** をクリック。
3. 発行されたURL（`https://<username>.github.io/ai-idol-kasu-umigame/`）にアクセスするだけで全世界に公開完了！
